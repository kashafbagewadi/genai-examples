## Gen-AI examples
This is a set of curated small GenAI applications designed for new learners using different LLMs.

### Applications
#### 1. Bug Classifier
Transforms an informal bug report into a clear, structured, and professional issue summary using OpenAI.

#### 2. Code Commenter
Generate the meaningful comment for existing code base with the help of AI.

#### 3. Comparator
Compares chipset used between two major iPhone models.



**Source of problem statements:**

KodeKloud 100 days AI Challenge

**Note:**
Code samples are refined/updated, and not exactly the same as accepted answer from the KodeKloud.
