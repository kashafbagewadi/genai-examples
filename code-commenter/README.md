## AI Code Commenter
Generate the meaningful comment for your existing code base with the help of AI.

### Description
When you starts working on an existing project, need to understnad the code-base before writting a single line of code. You can improve code readability and maintainability by automatically generating meaningful comments with the help of this simple Python module. 
It analyzes a code snippet and produces a clear, one-line comment or docstring describing its purpose.
It uses parameterized prompt or prompt template to construct the prompt for AI.
It accept a sample code snippet if no input provided

### AI model used
OpenAI - gpt-5.6-luna
