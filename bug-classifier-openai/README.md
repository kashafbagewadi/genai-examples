## Bug Classifier
Transform an informal bug report to a clear, structured, and professional issue summary

### Description
When DevOps team reports a bug to developer, they find difficulty to understand and reproduce the bug. This simple app helps them to classify and undersatand the bug in a professional, structured way with the help of AI. AI creates a bug summary that can be use to create a GitHub issue.

### AI model used
OpenAI - GPT-5.6-lune
