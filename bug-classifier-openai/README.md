## Bug Classifier
Transform an informal bug report into a clear, structured, and professional issue summary

### Description
When the DevOps team reports a bug to a developer, they find it difficult to understand and reproduce the bug. This simple app helps them to classify and understand the bug in a professional, structured way with the help of AI. AI creates a bug summary that can be used to create a GitHub issue.

### AI model used
OpenAI - GPT-5.6-lune

### Pre-requisite
1. API Key from OpenAI.
2. Export "OPENAI_API_KEY" and "OPENAI_API_BASE" as environment variables.
